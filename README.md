# 主動訊息 Proactive Messages

SillyTavern / TauriTavern 前端擴充：讓角色主動傳訊息給你。

## 三種情境

1. **回到聊天時他先開口**：距離上一則訊息超過設定的小時數，打開聊天（或從背景切回 App）時，他會主動傳一則，而且知道隔了多久。
2. **App 開著但你沒說話**：超過設定的分鐘數沒有動靜，他會主動找你聊。輸入框裡有字時不會打斷你。
3. **經期前後關心**：搭配「生理紀錄小幫手」，經期中、預計快來或晚到時，每天打開聊天會主動關心一次。

## 安全閥

- 每個角色要**個別開啟**（預設關閉）。
- 你沒回覆時，他最多連續主動幾則（預設 1 則），不會一直洗版。
- 每次主動訊息都是一次完整生成，token 花費和你自己送出一則差不多。

## 限制

插件只有在 App 開著時才能運作。App 關閉或在背景時（尤其手機），插件無法執行，也沒辦法發通知，要等你回到 App 才會觸發情境 1。

## 自訂

提示詞範本可以在設定裡修改，可用變數：`{{user}}` `{{char}}` `{{elapsed}}`（隔了多久） `{{now}}`（現在時間） `{{cycle}}`（經期狀態）。
